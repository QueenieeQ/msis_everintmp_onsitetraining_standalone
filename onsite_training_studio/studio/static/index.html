Boxes

    Drag on empty space to draw a new box for the selected label.
    Drag a corner to resize, drag inside to move, Delete key removes the selected box.
    Mouse wheel = zoom (centered on cursor). Shift+drag or middle-drag = pan.

    Onsite training

    Pick one shot + one model (e.g. left + screw head) to retrain only that model; the shot's other weights are kept. YOLO version "config default" uses the onsite YAML value.
    Training one shot only needs that shot's image — the other shots' images/annotations/weights are untouched and don't need to exist yet.
